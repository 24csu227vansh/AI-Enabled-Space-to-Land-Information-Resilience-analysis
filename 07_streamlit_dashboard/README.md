# Streamlit statistical dashboard — satellite information resilience

All statistical plots are generated by **Python / Matplotlib** from bundled CSV files, and displayed in **Streamlit**. No statistical plots are hard-coded screenshots.

## Windows / VS Code setup

1. Extract this ZIP to a folder.
2. Open the folder in VS Code.
3. Open a terminal in the folder and run:

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

If `py` is unavailable, use `python` instead.

Streamlit normally opens at http://localhost:8501 . Use the sidebar to navigate between graphs, inspect underlying tables, and download plots as PNG.

## Re-export all graphs as PNG

```powershell
py export_figures.py
```

PNG figures will appear in `figures/`. The code and source CSVs are included in the archive, so the plots can be independently reproduced.

## Figure mapping for the faculty-format paper

- Figure 1: methodology architecture — a conceptual diagram, **not** a statistical graph.
- Figure 2: RL performance, 3 training seeds.
- Figure 3: seed-level resilience indices.
- Figure 4: simulated correlated satellite dropouts.
- Figure 5: satellite cloud-percentage metadata prediction.
- Supplementary: simulated independent satellite dropouts.

## Important scientific limitations

- RL evaluation is synthetic and was not trained end-to-end on S1/S2 imagery.
- Three RL training seeds are insufficient for strong generalization claims.
- Dropout simulations describe information availability, not measured outages or land-cover accuracy.
- Satellite model predicts cloud-percentage metadata, not ground-truth land cover.
- Five satellite train/test splits overlap and must not be treated as independent experiments.
- Error bars represent seed/split standard deviations; they are not 95% confidence intervals.
- The original source imagery is not redistributed in this package.
